# If
Use if is very easy.
```
:if(cond)
    # cond is true
:else
    # cond is true
:fi
```
Example:
```
$bool(a, "true")
$bool(b, "true")
:if(a)
    $prints("1")
:else
    :if(b)
        $prints("2")
    :fi
    $prints("3")
:fi

```

Notice: Do not define the variable in if-else-fi, it will be ignore.
```
:if(a)
    $bool(b, false)
fi:
$and(true, b)
```
if the a is false, the script will throw error.
