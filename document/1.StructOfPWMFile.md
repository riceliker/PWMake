# 1. Struct of PWM File

There are the basic instruction about PWMake file.
## Annotation
Use `#` to ignore a line text.
``` PWM
# This Line Will Be Ignored.
```

## Group
Group is the yield with some member data. 
Use `@` to define a group and use `;` to end of group. 
``` PWM
@project("PWMake", "binary")
# TODO
;
```

## Member
Member is a function in Group.
In the end of function name, `!` mean must use in group, `?` mean optional use in group.
Use `()` mean parameter and use `,` to spilt.

## The Simple Project
Now let's look the simple project, which only have one file(hello.cpp).
``` PWM
@compiler("clang")
compiler_path!("/opt/homebrew/opt/llvm@19")
language_version!("c++23")
standard_library!("libc++")
;
@files("source_file")
add_file?("./src/main.cpp")
foreach_file?("./src", ".cpp")
;
@project("Hello", "binary")
source_files!("source_file")
;
```
