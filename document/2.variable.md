# Define a variable

## Define a user variable
PWMake support 2 types: bool and string
Use `$` to define a variable;
```
$bool(`type name`, true/false)
$string(`type name`, "`type value`")
```

## Use system variable
PWMake support that's system variable.
### 1. __platform__
It's a string, but it's value will be change by system platform.
It have that platform name:
1. "windows" 
2. "macos"
3. "linux"
```
$string(platform, __platform__)
$bool(platform, "linux")
```

### 2. __arch__
It's a string, but it's value will be change by CPU architecture.
It have that architecture:
1. "amd64"
2. "arm64"
```
$string(platform, __arch__)
$Equal(flag, platform, "linux")
```

## Bool Calculate
PWMake support that's bool and string calculate
### 1. Equal
compare two bool variable. If equal, return true.
```
$equal(`bool output`, `bool a`, `bool b`)
```

### 2. Not
If true, return false. If false, return true.
```
$not(`bool output`, `bool a`)
```

### 3. And
compare two bool variable. Both true return true.
```
$and(`bool output`, `bool a`, `bool b`)
```

### 4. Or
compare two bool variable. Both false return false.
```
$or(`bool output`, `bool a`, `bool b`)
```

## String Calculate
### 1. Same
compare two bool variable. If all same return true.
```
$same(`bool output`, `string a`, `string b`)
```

### 2. In
compare two bool variable. If a in b, return true.
```
$in(`bool output`, `string a`, `string b`)
```
