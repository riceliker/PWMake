# Files

## What is files group
Files group is a set which store the files.
You can use `foreach_folder` and `recursion_folder` to add many files once.
If you want to remove the file, use `remove_file`.
Notice: The root of search is the root of build file.

## Define a files
Use `@files` to define the files group.
```
@files("MyProgram")
```

## Add and remove a file
Use `add_file` and `remove_file`.
```
add_file("src/main.cpp")
remove_file("remove_file")
```

## Foreach and recursion a folder
The foreach folder will get all files under the folder. But not include subfolder.
The recursion folder will get all file under folder. Include subfolder.
```
foreach_folder("src", ".cpp")
recursion_folder("src", ".cpp")
```
