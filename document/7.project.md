# Project

## What is project
Project will link the file and link the library to build project.
You can build Binary Execute File, Static Library or Dynamic Library.

## Define a project
Use `@Project` to define
```
@Project("MyProgram", "binary")
```
"binary": the common binary execute file
"static": the static library
"shared": the dynamic library

## Add files and library
Use `add_files` and `add_library`
```
add_files("MyFiles")
add_library("/opt/homebrew/Cellar/sdl3/3.4.10/lib/libSDL3.0.dylib")
```
