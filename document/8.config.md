# Config
PWMake support write variable in config.pwm
If you build file is too big, it will help you.

## Format
Use `#` to ignore a line.
Use `=` to define a variable.
```
# This is the config file
compiler_path=/opt/homebrew/opt/llvm@19/bin/clang++
```
Notice: DO NOT have any Space near the define.
Notice: If you want to use annotation. The first word will must be #.
That's error:
```
compiler_path = /opt/homebrew/opt/llvm@19/bin/clang++
compiler_path=/opt/homebrew/opt/llvm@19/bin/clang++ # My annotation
```

## Use 
You can use the variable as common.
```
@compiler(compiler_path)
```
