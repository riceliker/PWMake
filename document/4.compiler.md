# Compiler Group
if you want to compile a program, you should have compiler
## Define a Compiler
use `@compiler` to define. The first param is the path of the compiler.
```
@compiler("/opt/homebrew/opt/llvm@19/bin/clang++")
    # TODO
;
```
the most of important thing is language and standard library.
```
@compiler("/opt/homebrew/opt/llvm@19/bin/clang++")
    compiler_language("c++23")
    standard_library("libc++")
;
```
## Optional Function
1. compiler_warning
Open the warning check when compile program
2. compiler_extra_warning
Open the extra warning check when compile program
3. compiler_debug
Use -O0 compiler for debug tool like clangd.
